# DevOps — Task 01

This repository contains exercises developed as part of the DevOps course at PUC Minas. The activity covers Node.js, Express, Git, GitHub, and GitHub Actions.

## Environment

- **Operating System:** Ubuntu 26.04
- **Containerization:** Docker 29.7.1
- **Runtime:** Node.js 22.23.3
- **Package Manager:** npm 10.9.9
- **Framework:** Express
- **Template Engine:** Pug
- **Code Editor:** Visual Studio Code 1.133.0
- **Version Control:** Git 2.53.0
- **Repository Hosting:** GitHub
- **CI/CD:** GitHub Actions
